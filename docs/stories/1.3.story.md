## Story

- As a **developer**

## Acceptance Criteria (ACs)

1. All models have factories with appropriate fake data
2. `php artisan db:seed` populates database with valid sample data
3. Seeded data includes at least:

   - 3 stages per competition with 2-4 measures each

5. Enum values are correctly set

**Coding Standards** [Source: docs/architecture/coding-standards.md]:

- Add PHPDoc blocks for clarity

**Database Schema** [Source: docs/architecture/database-schema.md]:
- Enum values:
  - competition.status: `draft`, `active`, `completed`
  - stage.status: `pending`, `active`, `complete`
- Nullable fields:
  - competitor: bar_name, instagram, diffords_profile
  - attempt: started_at, ended_at, duration_ms
  - stage: name

**Business Rules** [Source: docs/architecture/database-schema.md]:
- ONE attempt per competitor per stage (no retries)
- Competitors complete stages in series (not parallel)

### Factory Guidelines

**Faker Usage**:
- Use `$this->faker` in factories
- Common faker methods:
  - `name()`, `firstName()`, `lastName()`
  - `city()`, `countryCode()`
  - `date()`, `dateTimeBetween()`
  - `numberBetween()`, `randomFloat()`
  - `sentence()`, `words()`

**Realistic Data**:
- Competition names: e.g., "London Pour Test 2025", "NYC Bartender Challenge"
- Stage names: e.g., "Speed Round", "Precision Challenge", "Blind Pour"
- Measure names: e.g., "Vodka", "Gin", "Rum", "Tequila", "Whiskey"
- Target volumes: Common pour sizes (25ml, 35ml, 50ml, 75ml)
- Bar names: Real-sounding cocktail bars
- Instagram handles: @firstname_lastname format

### Testing

Manual Test Steps:
1. Run `docker compose exec app php artisan migrate:fresh --seed`
2. Check database in PHPMyAdmin (http://localhost:8080)
3. Verify:
   - 2 competitions exist (check status values)
   - Each competition has 3 stages
   - Each stage has 2-4 measures
   - 5 competitors exist
   - Active competition has competitors assigned
   - Active competition has attempts with results
4. Use tinker to verify relationships:
   ```bash
   docker compose exec app php artisan tinker
   >>> $comp = \App\Models\Competition::where('status', 'active')->first();
   >>> $comp->competitors()->count(); // Should be > 0
   >>> $comp->stages()->count(); // Should be 3
   >>> $comp->attempts()->count(); // Should be > 0
   ```
