# Story 3.2: Run a Competition Stage

## Status: Complete

## Story

- As a **referee**
- I want to **select a competitor and run a single stage of a competition**
- so that **I can record their performance accurately.**

## Acceptance Criteria (ACs)

1.  A "Run" button is visible on the competition edit page (`/admin/competitions/{id}`) for competitions with `status = 'draft'`.
2.  Clicking "Run" changes the competition `status` to `active` and redirects to the new "Run Dashboard" (`/run/competition/{id}`).
3.  The Run Dashboard displays the list of assigned competitors and the competition's stages.
4.  From the dashboard, the referee can select a competitor and a stage to begin an "attempt".
5.  This action navigates to the "Attempt Screen" (`/run/competition/{id}/competitor/{competitor_id}/stage/{stage_id}`).
6.  The Attempt Screen shows the target measures for the stage, a prominent start/stop timer, and input fields for the poured amounts.
7.  The timer starts when the "Start" button is clicked and stops when "Stop" is clicked. The duration is recorded.
8.  After stopping the timer, the referee can enter the `poured_ml` for each measure and save the results.
9.  Saving the results creates an `attempt` and associated `attempt_result` records.
10. After saving, the referee is redirected back to the Run Dashboard, where the completed attempt is indicated.

### Technical Implementation Details

**Timer Functionality:**
- High-precision timer updating every 10ms
- Records ISO 8601 formatted timestamps for started_at and ended_at
- Calculates duration in milliseconds
- Prevents form submission until timer is stopped
- Warns user before navigating away during timing

**Validation:**
- Competitor must be assigned to competition (verified in createAttempt)
- Stage must belong to competition (verified in createAttempt)
- All measure values required with minimum 0
- Started_at and ended_at timestamps validated
- Duration_ms must be positive integer

**UI/UX Features:**
- Status badges with color coding (green for completed, red for disqualified)
- Real-time difference calculation from target pour amounts
- Visual feedback for accuracy (green/red based on 2ml threshold)
- Recent attempts log for quick review
- Comprehensive error messaging
- Responsive grid layout for competitor/stage matrix
