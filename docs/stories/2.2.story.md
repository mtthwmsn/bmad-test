### Architecture Context

**CompetitionController** [Source: docs/architecture/backend-architecture.md]:

Routes:
- `GET /admin/competitions` → `index()` - List all competitions
- `GET /admin/competitions/create` → `create()` - Show create form
- `POST /admin/competitions` → `store()` - Save new competition
- `GET /admin/competitions/{id}/edit` → `edit()` - Show edit form
- `PUT /admin/competitions/{id}` → `update()` - Update competition
- `DELETE /admin/competitions/{id}` → `destroy()` - Delete competition

**Validation Rules**:
- `name`: required, string, max:255
- `city`: required, string, max:255
- `country_code`: required, string, size:2 (ISO 3166-1 alpha-2)
- `date`: required, date
- `status`: required, in:draft,active,completed

**Coding Standards** [Source: docs/architecture/coding-standards.md]:
- Use `declare(strict_types=1);` at top of all PHP files
- Type hint all methods
- Use Form Request classes for validation
- Keep controllers thin

### Implementation Details

**Controller Structure**:
```php
class CompetitionController extends Controller
{
    public function index(): View
    {
        $competitions = Competition::orderBy('date', 'desc')->paginate(10);
        return view('admin.competitions.index', compact('competitions'));
    }

    public function store(StoreCompetitionRequest $request): RedirectResponse
    {
        Competition::create($request->validated());
        return redirect()->route('admin.competitions.index')
            ->with('success', 'Competition created successfully.');
    }

    // ... other methods
}
```

**Status Badge Colors**:
- `draft`: gray (bg-gray-100 text-gray-800)
- `active`: green (bg-green-100 text-green-800)
- `completed`: blue (bg-blue-100 text-blue-800)
