### Implementation Details

**Controller Structure (CompetitorController)**:
```php
class CompetitorController extends Controller
{
    public function index(Request $request): View
    {
        $query = Competitor::query();

        // Search
        if ($search = $request->input('search')) {
            $query->where(function($q) use ($search) {
                $q->where('first_name', 'like', "%{$search}%")
                  ->orWhere('last_name', 'like', "%{$search}%");
            });
        }

        // Country filter
        if ($country = $request->input('country')) {
            $query->where('country_code', $country);
        }

        $competitors = $query->orderBy('last_name')->paginate(20);
        $countries = Competitor::select('country_code')->distinct()->pluck('country_code');

        return view('admin.competitors.index', compact('competitors', 'countries'));
    }

    public function store(StoreCompetitorRequest $request): RedirectResponse
    {
        Competitor::create($request->validated());
        return redirect()->route('admin.competitors.index')
            ->with('success', 'Competitor created successfully.');
    }

    public function update(UpdateCompetitorRequest $request, Competitor $competitor): RedirectResponse
    {
        $competitor->update($request->validated());
        return redirect()->route('admin.competitors.index')
            ->with('success', 'Competitor updated successfully.');
    }

    public function destroy(Competitor $competitor): RedirectResponse
    {
        if ($competitor->attempts()->exists()) {
            return redirect()->route('admin.competitors.index')
                ->with('error', 'Cannot delete competitor with existing attempts.');
        }

        $competitor->delete();
        return redirect()->route('admin.competitors.index')
            ->with('success', 'Competitor deleted successfully.');
    }
}
```

**Duplicate Detection in StoreCompetitorRequest**:
```php
public function withValidator($validator)
{
    $validator->after(function ($validator) {
        $exists = Competitor::where('first_name', $this->first_name)
            ->where('last_name', $this->last_name)
            ->exists();

        if ($exists) {
            $validator->errors()->add('first_name', 'A competitor with this name already exists.');
        }
    });
}
```

**Competitor Assignment Logic**:
```php
// In CompetitionController
public function assignCompetitors(Request $request, Competition $competition): RedirectResponse
{
    $request->validate([
        'competitor_ids' => 'required|array',
        'competitor_ids.*' => 'exists:competitors,id'
    ]);

    $competition->competitors()->sync($request->competitor_ids);

    return redirect()->route('admin.competitions.edit', $competition)
        ->with('success', 'Competitors assigned successfully.');
}

public function unassignCompetitor(Competition $competition, Competitor $competitor): RedirectResponse
{
    $competition->competitors()->detach($competitor->id);

    return redirect()->route('admin.competitions.edit', $competition)
        ->with('success', 'Competitor unassigned successfully.');
}
```
