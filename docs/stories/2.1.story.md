### Implementation Approach

**Laravel Breeze**:
We'll use Laravel Breeze (Blade stack) for simplicity:
- Provides login, logout, password reset
- Minimal, clean implementation
- Easy to customize
- No heavy JavaScript framework required

**Disabling Registration**:
Remove these routes from `routes/auth.php`:
- `Route::get('/register', ...)`
- `Route::post('/register', ...)`

Remove these views:
- `resources/views/auth/register.blade.php`
