# Story 1.1: Laravel Project Setup and Configuration

## Status: Done

## Story

- As a **developer**
- I want **to initialize a new Laravel 10+ application with MariaDB configuration**
- so that **we have a working foundation to build the Pour Test Competition App**

## Acceptance Criteria (ACs)

1. Laravel application runs successfully on `php artisan serve`
2. Database connection to MariaDB is successful
3. Default Laravel migrations run without errors
4. Application environment is configured for development

## Tasks / Subtasks

- [ ] Task 1: Install Laravel 10+ framework (AC: 1)
  - [ ] Run `composer create-project laravel/laravel .` in project root
  - [ ] Verify Laravel version is 10 or higher
  - [ ] Confirm directory structure is created correctly

- [ ] Task 2: Configure database connection for MariaDB (AC: 2)
  - [ ] Update `.env` file with MariaDB credentials
    - Set `DB_CONNECTION=mysql` (MariaDB uses MySQL driver)
    - Set `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`
  - [ ] Test database connection using `php artisan migrate:status`

- [ ] Task 3: Configure basic application settings (AC: 4)
  - [ ] Set `APP_NAME="Pour Test Competition"` in `.env`
  - [ ] Set `APP_ENV=local` for development
  - [ ] Set `APP_DEBUG=true` for development
  - [ ] Configure `APP_TIMEZONE` (if needed for competition timing)
  - [ ] Set `APP_LOCALE=en`

- [ ] Task 4: Run default Laravel migrations (AC: 3)
  - [ ] Execute `php artisan migrate`
  - [ ] Verify migrations table is created
  - [ ] Verify users and other default tables are created

- [ ] Task 5: Verify application serves correctly (AC: 1)
  - [ ] Run `php artisan serve`
  - [ ] Access application at `http://localhost:8000`
  - [ ] Verify Laravel welcome page displays
  - [ ] Check for any errors in console or browser

- [ ] Task 6: Basic project configuration
  - [ ] Configure session driver in `.env` (default: `SESSION_DRIVER=file`)
  - [ ] Configure cache driver in `.env` (default: `CACHE_DRIVER=file`)
  - [ ] Create `.env.example` with template settings (if not exists)
  - [ ] Commit initial Laravel installation to git (if using version control)

## Dev Notes

### Architecture Context

**Tech Stack** [Source: docs/architecture/tech-stack.md]:
- Backend: PHP 8.1+, Laravel 10.x or 11.x
- Database: MariaDB (latest stable)
- Templating: Blade (Laravel native)
- Frontend: Server-rendered views with vanilla JavaScript
- Testing: PHPUnit (unit/feature), Codeception (browser)

**Project Type**: Greenfield full-stack web application for managing Pour Test competitions

### Key Technical Details

**Database Configuration** [Source: docs/architecture/tech-stack.md]:
- MariaDB uses the MySQL driver in Laravel (`DB_CONNECTION=mysql`)
- Ensure MariaDB server (10.3+) is running before testing connection
- Default port for MariaDB: 3306
- Required PHP extensions: PDO, Mbstring, OpenSSL, XML, etc. (see tech-stack.md)

**Laravel Version** [Source: docs/architecture/tech-stack.md]:
- Use Laravel 10.x or 11.x (latest stable)
- Laravel 10+ requires PHP 8.1 minimum
- Composer 2.x required for dependency management

**Environment Setup**:
- Development environment should have `APP_DEBUG=true`
- Session and cache drivers can use `file` for initial setup (simple, no Redis needed yet)
- Environment file `.env` must be created from `.env.example`

**Coding Standards** [Source: docs/architecture/coding-standards.md]:
- Use strict types: `declare(strict_types=1);` at top of all PHP files
- Follow PSR-12 coding standards
- Use Laravel Pint for automatic code formatting
- Type hint all parameters and return types

1. **Docker Environment**: Implemented Docker containerization instead of local PHP installation
   - Created `Dockerfile` with PHP 8.2-FPM

   - Created PHP configuration in `docker/php/local.ini`

2. **Laravel Version**: Installed Laravel 11.x (latest) instead of Laravel 10.x
   - Laravel 11 includes modern features and is compatible with PHP 8.2
   - No breaking changes affecting our architecture

3. **Additional Files Created**:
   - `README.md`: Comprehensive Docker setup and usage instructions
   - `.gitignore`: Standard Laravel gitignore with Docker-specific additions

**Key Implementation Details**:
- Database host is `db` (Docker service name) instead of `localhost`
- Application accessible at `http://localhost:8000` (Nginx)
- PHPMyAdmin available at `http://localhost:8080` for database management
- All Laravel commands must be run with `docker compose exec app` prefix
- File permissions managed through Docker user `pourtest`
